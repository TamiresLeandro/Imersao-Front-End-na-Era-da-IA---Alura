# 🚀 Imersão Front-End na Era da IA - Alura

Este projeto foi desenvolvido durante a **Imersão Front-End da Alura**, uma jornada prática focada em construir uma aplicação web moderna utilizando o apoio de ferramentas de Inteligência Artificial.

## 💻 Sobre o Projeto
O objetivo principal é criar uma interface inspirada em plataformas de streaming (como a Netflix), explorando as principais etapas do desenvolvimento front-end moderno.

## 🛠️ Tecnologias e Ferramentas
* **HTML5** e **CSS3** para estruturação e estilização.
* **JavaScript** para interatividade.
* **Inteligência Artificial** como copiloto no processo de codificação e resolução de problemas.
* **Vercel/GitHub Pages** para publicação da página.

## 📖 O que aprendi nesta Imersão
* **Aula 01:** Introdução ao desenvolvimento front-end e estruturação da base do projeto.
* **Aula 02:** Finalização do HTML semântico, introdução ao CSS (estilização externa e hierarquia de seletores) e estruturação do layout visual com auxílio de IA.
* **Aula 03:** Implementação de Light/Dark Mode com JavaScript, uso de Variáveis CSS para gerenciamento de temas e aplicação de responsividade assistida por IA.

## 🎨 Layout
A interface é baseada em uma plataforma de streaming, focando em:
- Responsividade (mobile-friendly).
- Experiência do usuário (UX).
- Design moderno.
